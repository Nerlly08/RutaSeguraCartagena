# Semillas de Dignidad | Ruta Segura Cartagena

Prototipo académico de orientación y prevención de la trata de personas y la violencia contra niñas, niños y adolescentes.

**Importante:** Este proyecto es una demostración educativa; no recibe denuncias, no transmite alertas a autoridades y no sustituye los canales oficiales. En Colombia, ante una emergencia llama al 123; para protección de menores, línea 141 del ICBF.

## Publicación

La página principal será `index.html`. Las imágenes utilizadas deben estar en la misma carpeta que `index.html`: `referencia_portada.jpg`, `aislamiento.jpg`, `riesgo_digital.jpg` y `acompanamiento.jpg`.

## Uso de imágenes

Las fotografías son ilustrativas y no deben presentarse como imágenes de víctimas reales. Verificar los permisos de uso antes de publicar.
